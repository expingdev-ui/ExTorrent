# ExTorrent 🧲

**A torrent client for Windows** with an integrated search feature and a graphical user interface (GUI).

## ✨ Features

✅ Download via magnet links
✅ Support for .torrent files
✅ Built-in torrent search (apibay.org)
✅ Pause/Resume/Stop functionality
✅ Selectable download directory
✅ Russian-language interface
✅ Content search engine (English only)

## 🛠️ Technical Details

Developed to explore:
- 🔗 P2P protocols (BitTorrent)
- 🧵 Multithreading in Python
- 🎨 GUI development using `customtkinter`
- 📡 Interacting with external APIs

## 📋 Requirements

- Windows 7+
- Python 3.11+
- `libtorrent`, `customtkinter`, `requests`

## 🚀 Installation

```bash
pip install -r requirements.txt
python ExTorrent.py
```

## 🎮 Usage

1. **Search for a torrent** — enter a name and select from the results.
2. **Add a magnet link** — copy and paste it.
3. **Or upload a .torrent file.**
4. **Choose a folder** for your downloads.
5. **Click Start** and wait!

### Controls

- **Pause** — pause the download.
- **Resume** — resume the download.
- **Stop** — stop and remove the torrent.
- **Change Folder** — select a different download directory.
